# Irigate 0.4.1

Release date: 2026-07-26

## Highlights

- Irigate is now installed from PyPI as the supported distribution channel. This is a packaging-only patch release; runtime behavior is unchanged from 0.4.0.

## Added

- A tag-gated GitHub Actions release pipeline that tests and builds the wheel and source distribution, publishes through PyPI Trusted Publishing, and then creates the matching GitHub Release with those exact artifacts.
- Maintainer documentation for Trusted Publisher setup, release preparation, immutable tags, fresh-install verification, and failure recovery.

## Changed

- `uv tool install irigate` is the recommended user installation command.
- `python -m pip install irigate` is supported inside a virtual environment.
- Package metadata now links the homepage, source repository, issue tracker, and changelog from PyPI.

## Fixed

- Release verification now checks that the source and packaging version declarations agree before artifact publication.

## Install or upgrade

```sh
uv tool install irigate
# Existing installation:
uv tool upgrade irigate
irigate --version
```

Irigate requires Python 3.11 through 3.14. Existing installations from the 0.4.0 GitHub Release can move to PyPI with `uv tool install --force irigate`; no profile migration is required.

## Known limitations

- Irigate remains a loopback-only local MCP broker; it is not a remote, multi-tenant, or enterprise control plane.
- PyPI Trusted Publishing must be configured once in both PyPI and the repository's `pypi` GitHub environment before the first tag can publish.

## Verification

- Package: <https://pypi.org/project/irigate/>
- Verify a fresh installation with `irigate --version` and `irigate --help` before configuring a broker profile.
