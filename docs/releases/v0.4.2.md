# Irigate 0.4.2

Release date: 2026-07-26

## Highlights

- PyPI now publishes the current README, including WSL/Windows bridging documentation, with a logo link that works outside the repository checkout.

## Fixed

- The README project mark uses an absolute GitHub raw URL so PyPI does not resolve `assets/logo.svg` relative to its own page.

## Install or upgrade

```sh
uv tool install irigate
# Existing installation:
uv tool upgrade irigate
irigate --version
```

Irigate requires Python 3.11 through 3.14. No profile migration or additional installation step is required.

## Known limitations

- Irigate remains a loopback-only local MCP broker; it is not a remote, multi-tenant, or enterprise control plane.
